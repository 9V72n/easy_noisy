# 意識・存在・宇宙のやさしい地図

## 中身

- `index.html` — 全22章を1ページにまとめた読み物サイト（目次サイドバー・読書プログレス・ダーク対応）
- `意識・存在・宇宙のやさしい地図.epub` — 電子書籍版（ページ左上のリンクからダウンロード可能）
- `.nojekyll` — GitHub Pages の Jekyll 処理を無効化（日本語ファイル名対策）
