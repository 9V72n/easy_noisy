# 意識・存在・宇宙のやさしい地図

「在る」と「感じる」をめぐる、だれにでも読める案内書

『ノイジーゲート』による、原典『意識・存在・宇宙の統合体系』のやさしい読み物版です。

## 中身

- `index.html` — 全22章を1ページにまとめた読み物サイト（目次サイドバー・読書プログレス・ダーク対応）
- `意識・存在・宇宙のやさしい地図.epub` — 電子書籍版（ページ左上のリンクからダウンロード可能）
- `.nojekyll` — GitHub Pages の Jekyll 処理を無効化（日本語ファイル名対策）

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作成する。
2. この `github-pages/` フォルダの中身を、リポジトリ直下に置いて push する（`index.html` がトップに来るように）。
3. リポジトリの **Settings → Pages** を開く。
4. *Source* = **Deploy from a branch**。
5. **Branch = main**、フォルダ **/ (root)** を選んで Save。
6. 数十秒〜数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

`docs/` フォルダに入れて手順5で **/docs** を選んでも公開できます。
